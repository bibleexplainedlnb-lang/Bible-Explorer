Fix Bulk Generation + "Created ✔" Sync Issue (End-to-End)

Problem:
- Single article generation shows "✔ Created"
- Bulk generation creates articles but UI does NOT update
- Admin becomes inconsistent and misleading

Goal:
Ensure ALL articles (bulk/manual/single) behave the same and UI always reflects DB truth.

==================================
1. BACKEND FIX (CRITICAL)
==================================

Update bulk generation logic:

- Every generated article MUST have:
    status = 'published'
    topic_id = correct topic.id

Example:
INSERT INTO articles (
  title,
  slug,
  content,
  topic_id,
  status
)
VALUES (
  ...,
  topic.id,
  'published'
);

❗ Never default to 'draft' unless explicitly selected

----------------------------------
Add Control Toggle:
----------------------------------

In bulk generator UI:

[ ] Save as Draft  
[x] Publish immediately (DEFAULT)

Backend behavior:
- If toggle OFF → status = 'published'
- If toggle ON → status = 'draft'

==================================
2. DATA INTEGRITY CHECK
==================================

Ensure after bulk generation:

- topic_id IS NOT NULL
- status is correctly saved

Debug query:
SELECT title, topic_id, status
FROM articles
ORDER BY created_at DESC
LIMIT 20;

==================================
3. API FIX (SOURCE OF TRUTH)
==================================

Update topics API:

SELECT t.id, t.name,
EXISTS (
  SELECT 1 FROM articles a
  WHERE a.topic_id = t.id
  AND a.status = 'published'
) AS is_created,
(
  SELECT COUNT(*)
  FROM articles a
  WHERE a.topic_id = t.id
  AND a.status = 'published'
) AS article_count
FROM topics t;

==================================
4. FRONTEND FIX (UI LOGIC)
==================================

Remove old logic:
❌ Do NOT check generation source

Use:
✔ is_created (boolean)

UI Rules:

IF is_created = true:
  show → ✔ Created (green)

Optional upgrade:
- show count → "✔ 5 Articles"

IF no published articles:
  show nothing OR "Not Created"

==================================
5. AUTO REFRESH (IMPORTANT)
==================================

After bulk generation completes:

- Re-fetch topics API
OR
- Trigger UI refresh automatically

==================================
6. CONSISTENCY RULE (VERY IMPORTANT)
==================================

"Created ✔" MUST depend ONLY on:

✔ EXISTS published article in DB

NOT:
- how article was generated
- which UI was used

==================================
7. FINAL GOAL
==================================

✔ Bulk generated articles show "✔ Created"
✔ Manual articles show "✔ Created"
✔ Single generated articles show "✔ Created"
✔ UI always reflects real database state
✔ No mismatch ever again
